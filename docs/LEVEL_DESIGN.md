# 쥐들의 전쟁 — 스테이지 레벨 디자인 계획 (2026-10-27)

결정 사항 (사용자): **맵 크기는 임무 성격마다 다르게**, **캠페인은 막(幕)별 선형 확장**.

---

## 1. 설계 기준 수치 (지금 규칙에서 나온 값)

| 항목 | 값 | 레벨 디자인에 주는 뜻 |
|---|---|---|
| 분대 | 최대 6마리 | 진입로 하나에 2~3마리씩, 갈래 2~3개가 알맞음 |
| 이동 | 5~7칸 (행동력 2개 = 질주 10~14칸) | 엄폐 → 다음 엄폐 간격 **4~6칸** |
| 시야 | 8칸 (+언덕 1, 저격 · 정찰 +2) | 무리(pod) 사이 간격 **9~14칸** = 한 번에 두 무리를 깨우지 않음 |
| 무리 깨우기 | 6칸 안에서 서로 보이면 | 높은 엄폐(벽 · 나무 · 집)로 시선을 끊어 "방"을 만들면 기습 · 측면 각이 생김 |
| 명중 | 낮은 엄폐 −20 · 높은 엄폐 −40 · 고지 +20 · 측면 치명 +40 | 고지 · 측면 자리 하나가 판을 뒤집음 → 맵마다 **"뺏을 자리" 1~2곳** |
| 진지 | 박격포(M) · 중기관총(G) | 진지는 맵의 목표물 겸 위험물. 고양이가 쓰면 위협, 쥐가 뺏으면 보상 |

### 공간 규칙
1. **시작 지점은 안전**: 쥐 출발 줄 6칸 안에 고양이 시선 없음, 엄폐 3곳 이상.
2. **첫 접촉은 2~3턴 차**: 첫 무리는 출발점에서 10~14칸.
3. **갈래 2~3개**: 정면(엄폐 많고 느림) · 측면(엄폐 적고 빠름) · 우회(철조망 · 갉기 · 땅굴 · 벽 타기로만 열림).
4. **방 → 복도 → 방**: 높은 엄폐 덩어리로 구역을 나누고, 구역 사이는 좁은 통로(2~4칸). 통로 끝 = 경계 사격 각.
5. **엄폐 밀도**: 한 번 이동 범위(6칸 원) 안에 엄폐 칸 3개 이상. 단, 진지 앞 "죽음의 땅"은 일부러 비움 (연막 · 제압 · 땅굴로 건너는 재미).
6. **병종 놀이터**: 맵마다 특정 병종이 빛나는 자리 1곳 (공병 = 벽 폭파 지름길, 코만도 = 벽 너머 칼, 저격 = 긴 사선, 의무병 = 엄호 받는 후방).
7. **바깥은 막힘을 그림으로**: 맵 가장자리는 철조망 · 폐허 · 물 · 날개 배경층으로 자연스럽게 닫음.

## 3. 임무 종류

| 목표 | 지금 | 설명 |
|---|---|---|
| 전멸 (elim) | 있음 | 기본 |
| 표적 (officer) | 있음 | 장교 하나. 쓰러뜨리면 나머지 흩어짐 |
| 깃발 (reach) | 있음 | 쥐 한 마리라도 깃발 칸에 |
| **탈출** (extract) | 새로 | n마리가 탈출 구역에 들어가면 끝. 쓰러진 쥐는 업어 가야 함 |
| **방어** (hold) | 새로 | n턴 버티기, 매 턴 고양이 증원 |
| **파괴** (sabotage) | 새로 | 목표물(무전탑 · 대포)에 폭약 · 수류탄 |
| **구출** (rescue) | 새로 | 포로 쥐(새 병사로 합류) 데리고 탈출 |
| **증원** (공통 장치) | 새로 | 정해진 턴 · 경보에 맵 가장자리로 고양이 무리 투입 |

| 막 | 고양이 수 | 조준 보정 | 무리 구성 | 보상(보급품) |

## 6. 제작 방식 · 엔진 준비

- **맵 = 데이터**: `Assets/Resources/Data/maps.json` · `missions.json` (코드에 박지 않음).
  - 맵 = 기호 줄(rows) + 언덕 타원(hills) + 출발 칸(spawn). 기호는 지금과 같음
    (`.` 풀 `,` 진흙 `=` 길 `o` 구덩이 · `S` 모래주머니 `C` 상자 · `W` 벽 `T` 나무 `R` 트럭 `H` 돌집 · `X` 철조망 · `M` 박격포 `G` 기관총)
  - 임무 = 맵 이름 + 좌우 뒤집기 + 목표 + 고양이 배치(병과 · 머리 · 무리 · 표적).
- **생성 · 검사 도구** `tools/maps/build_maps.js`: 맵을 "도장 찍기"(벽 · 참호선 · 건물 외곽 · 흩뿌리기)로 짜서 기호 줄로 뽑고, 아래를 자동 검사
  - 줄 길이 · 기호 오류 / 출발 칸 · 고양이 칸이 걸을 수 있는지 / 출발점에서 모든 고양이 · 깃발까지 길이 있는지 / 출발점 6칸 안 엄폐 수 / 무리 간 거리
- **엔진 확장 순서** (막을 만들 때 필요한 것만)
  1. (1막) 크기 가변 · 데이터 맵 · 큰 맵 굽기 축소 ← 이번
  2. (2막) 새 지형 칸: 얕은 물 · 다리 · 건물 안 / 목표: 파괴 · 구출 / 증원 장치
  3. (3막) 여러 층 높이(h 0~2) · 숲 시야 / 목표: 탈출
  4. (4막) 문 · 실내 · 보스 단계 전환
- **그림 필요 목록** (ChatGPT 대기열에 추가)
  - 2막: 물 · 다리 무늬, 공장 소품(컨베이어 · 드럼통), 방패병 리그
  - 3막: 숲 덤불 판, 성당 종탑 · 수도원 성벽 소품, 군견 고양이 리그
  - 4막: 벙커 벽 · 문 · 대공포 소품, 친위대 · 총통 고양이 리그

## 7. 1막 맵 메모 (이번 제작분)

### 1-1 하수구 출구 (S 20×26)
- 아래 = 하수구 둑(출발), 가운데 = 생울타리 밭, 위 = 마을 외곽 집 두 채.
- 갈래: 가운데 길(엄폐 많음) / 양옆 나무줄(빠름) / 철조망은 양끝만 막아 가운데로 모음.
- 무리: A 밭 가운데(2) → B 모래주머니 줄(기관총 1 + 1) → C 마을 길목(장교 + 2).

### 1-2 언덕 위의 박격포 (M 24×34)
- 기존 언덕 맵 + **앞쪽 농장 접근로 12줄**(농가 벽 · 건초 상자 · 생울타리) + 양옆 3칸.
- 첫 무리(농장 지킴이 2)가 출발점 12칸 앞. 언덕 박격포 진지 = 뺏을 자리.

### 1-3 철도역의 장교 (M 24×34)
- 기존 철도역 맵 + 앞쪽 **화물 적치장 12줄**(트럭 잔해 · 상자 더미) + 양옆 3칸.
- 표적 장교는 맨 뒤 기관총 진지 곁. 철길(가로 길)이 사선을 열어 줌 → 저격수 놀이터.

### 1-B 참호선 돌파 (L 30×44)
- 아래부터: 아군 참호(출발) → 무인지대(구덩이 · 철조망 토막 · 트럭 잔해) → 1차 참호(기관총 진지 2) → 폐농가 → 2차 참호 → 언덕 박격포 → 지휘 벙커(돌집 벽으로 두른 방, 문 하나).
- 보스 = 독재 고양이 장교(표적). 진지 기관총 2문은 쥐가 뺏으면 2차 참호를 쓸 수 있음.
