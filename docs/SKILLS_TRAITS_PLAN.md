# 병종 액티브 스킬 · 캐릭터 특성 고도화 계획서

> 작성 2026-10-30 · 대상 코드: `Data/GameData.cs` (ABILITIES) · `Data/SkillsData.cs` (스킬판 · 병종) · `Data/Camp.cs` (TRAITS) · `Battle/Battle.cs` (GetHitInfo · 능력 실행)
> 목표: **병종마다 "이 쥐만 할 수 있는 결정적 한 수"** 를 2~3개씩 주고, **특성을 숫자 보정이 아니라 전투 중 사건에 반응하는 성격**으로 바꿔서 쥐 한 마리 한 마리에 대한 애착을 키움.

## 0. 지금 상태 진단

### 스킬
| 병종 | 지금 고유 능력 | 문제 |
|---|---|---|
| 소총수(신병) | 잽싼 발 | 괜찮음 — 신병은 단순해야 함 |
| 저격수 | 쥐구멍 매복 (+스킬판 정조준) | 매복 → 사격 한 패턴뿐. 가까이 붙으면 할 게 없음 |
| 기관총 사수 | 제압 사격 · 찍찍 함성 | 함성이 전투당 1번, 제압이 사실상 유일한 선택지 |
| 공병 | 폭약 · 철조망 갉기 (+땅굴 · 화염) | 이미 풍부함. 대신 **방어적인** 수단이 없음 |
| 코만도 | 칼 | 칼 한 번 쓰고 나면 고양이 사이에 고립됨 → 빠져나올 수단 없음 |
| 의무병 | 응급 처치 · 치즈 | 다 '1AP 붙어서 쓰기'. 위치 선정 말고는 판단할 게 없음 |
| 정찰병 | 표적 지정 | 시야 · 수염이 수동이라 손이 갈 액티브가 하나 |
| 통신병 | 쥐떼 전령 · 무전 탐지 | 탐지가 전투당 1번이라 나머지 턴은 전령만 |
| 주술사 | 정신 지배 · 마법 방어막 | 정신력 3으로 지배 1번 + 방어막 1번이면 끝 |

공통: 능력에 **재사용 대기(쿨타임)** 개념이 없어서 `once`(전투당 1번) 아니면 '매 턴 무제한' 둘 중 하나. 그래서 강한 능력은 전부 1회용이 되고, 약한 능력만 반복해서 씀.

### 특성
- 31개 중 **약 20개가 상시 숫자 보정**(명중 +5, 이동 +1 …). 전투 중에 "아, 이 쥐는 이런 쥐였지" 하는 순간이 거의 안 옴.
- 상황 반응형은 `지휘관 곁` · `외톨이` · `복수심` · `골초` · `피에 굶주림` 정도뿐.
- 특성은 **모집 때 정해지면 끝**. 전투 경험으로 성격이 바뀌는 일이 없음 → 오래 산 쥐도 이야기가 쌓이지 않음.

## 1. 시스템 추가 (스킬 · 특성 공통 기반)

먼저 데이터에 아래 필드를 넣으면 이후 스킬 · 특성을 전부 데이터로 추가할 수 있음.

### 1-1. `AbilityDef` 확장
| 필드 | 뜻 | 예 |
|---|---|---|
| `cd` | 재사용 대기 턴 (쓰고 나서 N턴 뒤 다시) | 연막탄 `cd = 3` |
| `uses` (이미 있음) | 전투당 횟수. 화염방사기에만 쓰던 걸 일반화 | 부비트랩 `uses = 2` |
| `free` | 행동력은 쓰되 턴을 안 끝냄 (`end = false` 와 같음, 이름만 정리) | — |
| `shape` | 범위 모양: `circle` · `cone` · `line` | 난사 `cone` |
| `ammo` | 탄 몇 발 씀 | 난사 = 탄창 전부 |
| `requires` | 조건: `noMove` · `inCover` · `adjacent` · `flank` | 정조준 `noMove` |

`Unit` 에 `Dictionary<string,int> cooldown` 하나 추가, 턴 시작 처리(`Battle.cs:256` 부근)에서 1씩 깎음. `CanUse` 판정(`Battle.cs:959` 부근)에 `cd > 0` 이면 "N턴 뒤" 사유 추가.

### 1-2. `TraitDef` 확장 — 사건 훅
지금은 `n`(숫자) · `stressBy`(이유별 배율) 두 개뿐. 여기에 **언제 발동하는지**를 붙임.

| 훅 | 발동 시점 | 쓰는 특성 예 |
|---|---|---|
| `onTurnStart` | 그 쥐 차례 시작 | 골초(이미 있음), 기도하는 쥐 |
| `onKill` | 처치했을 때 | 피에 굶주림(이미 있음), 사냥꾼 |
| `onHit` | 맞았을 때 | 분노 조절 장애, 오뚝이 |
| `onAllyDown` | 근처 아군 쓰러짐 / 사망 | 복수심, 맏형 |
| `onFirstShot` | 그 판 첫 사격 | 기선 제압 |
| `hitMod(ctx)` | 명중 계산에 끼어듦 (거리 · 엄폐 · 주변 아군 등) | 외톨이 · 지휘관(이미 있음)을 이 구조로 옮김 |

구현은 `GetHitInfo` 안에 하드코딩된 특성 줄(`Battle.cs:222~224`)을 `foreach (trait) parts.AddRange(trait.HitMod(ctx))` 한 줄로 바꾸는 게 핵심. 이후 명중 관련 특성은 `Camp.cs` 에만 추가하면 됨.

### 1-3. 획득 특성 (전투 중 생기는 성격)
판 끝 정산(`Camp.Settle`)에서 **그 판에 있었던 일**을 보고 특성을 붙이거나 뗌. 한 쥐당 최대 5개, 넘으면 가장 오래된 일반 특성을 밀어냄.
- 전투 기록용으로 `BattleResult` 에 카운터 몇 개 추가: `knifeKills`, `nearExplosions`, `downedThenSaved`, `sawGore`, `flankKills`, `overwatchKills`, `turnsAlone`.
- 획득 확률은 기본 30~50%, "같은 일 3번째"엔 확정 같은 식으로 누적.

## 2. 병종별 액티브 스킬

### 2-0. 최종 구성 (2026-10-30 확정 · 질문으로 고름)
공용 행동(사격 · 경계 · 수류탄 · 재장전)은 세지 않음. **쿨타임 N** = 쓰고 나서 내 차례 N번 동안 못 씀 (1턴에 쓰면 N+1턴부터 다시).

| 병종 | 액티브 | 비고 |
|---|---|---|
| 소총수 | 없음 | 기본 신병 — 공용 행동만. **잽싼 발 삭제** |
| 저격수 | 쥐구멍 매복 · 정조준 | 기존 그대로 |
| 기관총 사수 | 제압 사격 · 찍찍 함성 · **난사** | 난사 새로 |
| 공병 | 폭약 · 땅굴 파기 · **부비트랩** | 땅굴 개편 · 철조망 갉기 → 패시브 · 화염방사기 → 무기 교체 |
| 코만도 | 칼 · **연막탄** · **그림자 돌진** | 둘 다 새로 |
| 의무병 | 응급 처치 · **진통제** · **대량 보급품** | 둘 다 새로. **치즈 배급 삭제** |
| 정찰병 | 표적 지정 · **조명탄** | 약점 간파 = 표적 지정 강화(스킬판) |
| 통신병 | 쥐떼 전령 · **포격 유도** | **무전 탐지 삭제** |
| 주술사 | 정신 지배 · **공포의 속삭임** · **정신 정화** | **마법 방어막 삭제** |

#### 화염방사기 → 무기 교체
- 폭파 갈래 r3 '화염방사기 장착' 칸을 찍으면 **공병 무기가 화염방사기로 바뀜**. 쓰기 싫으면 그 칸을 안 찍으면 됨 (능력이 아니라 무기라 공병 액티브 수에 안 셈).
- 화염방사기만 듦 (총 없음). **사격 = 화염 방사**, 연료가 떨어지면 재장전.

| 명중 | +15 |
| 범위 | 부채꼴 길이 4 · 폭 3, 범위 안 적 각각 굴림 |

## 4. 균형 원칙
- 액티브 하나의 기대 가치 ≈ 일반 사격 1.3~1.8발. 넘는 건 cd 3 이상 또는 uses 제한.
- 명중 보정 특성은 **±10 상한**, 상시 보정은 ±5. 조건부만 10.
- 특성은 쥐 한 마리에 **좋은 것 1~2 + 나쁜 것 0~1** 을 기본 분포로 (지금은 무작위라 '전부 나쁜 쥐'가 나옴).
- 고양이 쪽에도 대응 수단 하나씩: 연막 → 고양이 장교 "수색 명령"(연막 안 시야), 부비트랩 → 화염병이 덫 태움 등. (이번 범위 밖 · 메모만)

### 난이도 보정 (2026-10-30 게임에 들어감)

### 짚어 둘 점
1. **머리 10%는 치명이 아니어도 즉사.** 맞기만 하면 10%로 죽음 → 의도한 잔혹함이면 유지, 아니면 비치명 머리는 "피해 ×2" 로.
2. **회피(def)는 엄폐와 따로 그냥 더해짐.** 코만도(5) + 날쌘 발(10) + 행운아(5) + 겁쟁이(5) = 25 → 높은 엄폐 뒤면 −65. 상한(예: 30)을 두는 게 안전.
3. **기관단총 · 기관총 3연사는 연출만**, 굴림은 1번. 난사 · 연사 스킬을 넣을 거면 여기부터 '발당 굴림'으로 바꿀지 결정 필요.
4. 측면 판정은 "주변에 엄폐가 있는데 내 쪽을 안 막음"일 때만. 엄폐가 아예 없는 칸은 측면이 아니라 노출(+15)이라 **노출된 적이 측면 잡힌 적보다 치명이 낮음** — 직관과 반대.
5. 고지는 높이 차이만 봄(1칸이든 3칸이든 +20).
